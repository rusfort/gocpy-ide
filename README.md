# Gocpy IDE 0.1.0

Лёгкая IDE для языка gocpy под macOS. Это один Go-бинарник примерно на 7 МБ, внутри которого уже лежит веб-интерфейс (CodeMirror 6 + xterm.js). Он открывается отдельным окном без вкладок и адресной строки, через `--app` в Chrome, Edge, Brave или Chromium. Если ни одного из этих браузеров нет, IDE откроется в браузере по умолчанию.

## Экран

```
┌ Файл  Правка  Настройки ─────────── проект — путь ─────────── ▶ Запустить ■ ┐
│ ПРОВОДНИК (1/4)     │ main.gocpy (3/4)                                       │
│ ▾ proj              │  1 package main                                        │
│   ▸ pkg             │  2                                                     │
│   gocpy.yml         │  3 import "std/fmt"                                    │
│   main.gocpy        │  …                                                     │
├─────────────────────┴────────────────────────────────────────────────────────┤
│ ТЕРМИНАЛ (zsh, git…)              │ ВЫВОД ПРОГРАММЫ (stdout/stderr, stdin)   │
└───────────────────────────────────┴──────────────────────────────────────────┘
```

Все разделители можно перетаскивать. Двойной клик по разделителю возвращает размер по умолчанию.

## Возможности

- **Проводник.** Показывает дерево проекта. Через кнопки или правый клик можно создать файл или папку (вложенные пути вроде `pkg/util.gocpy` тоже работают), переименовать (Enter) и удалить (⌘⌫). Удалённое уходит в Корзину. Есть пункты «Показать в Finder» и «Копировать путь». Дерево обновляется само, когда окно IDE снова получает фокус, например после `git checkout`.
- **Редактор.** Одна вкладка. Есть номера строк, сворачивание блоков `{}`, автоотступы и автозакрытие скобок, поиск и замена (⌘F), переход к строке (⌃G), комментирование (⌘/), множественные курсоры. Если файл изменился на диске, IDE это заметит.
- **Терминалы.** Это настоящие PTY. Слева — ваш login-shell в папке проекта, в нём работают git, ssh, vim, htop и т. д. Справа — вывод программы. Туда можно печатать, ввод уходит в stdin программы.
- **Запуск.** Кнопка ▶, ⌘R или F5 сохраняет файл и выполняет `gocpy run <проект>`. ■ или ⇧F5 останавливает программу: сначала SIGINT всей группе процессов, через 1,5 с — SIGKILL. После завершения показываются код выхода и время работы.
- **Проекты.** Создание, открытие, «Сохранить проект как…» (копия в новую папку), недавние проекты. Папки выбираются в нативных диалогах macOS. Новый проект сразу получает `main.gocpy`, `gocpy.yml` и `.gitignore`.
- **Настройки.** Путь к `gocpy` и шаблон команды запуска (`{gocpy} {project} {file} {dir} {name}`), шрифты, табы или пробелы, перенос строк, скрытые файлы, shell.
- **Подсветка.** Отдельная таблица «что подсвечиваем — цвет» на 77 элементов. У каждого цвета есть квадратик с системной палитрой, поле HEX и сброс к значению по умолчанию. Также есть фильтр и общий сброс. Изменения видны в редакторе сразу.

## Что подсвечивается

Подсветка семантическая. Сначала файл проходит лексер, повторяющий лексер компилятора gocpy, а затем отдельный анализ объявлений:

| Группа | Элементы |
|---|---|
| Ключевые слова | управление потоком, объявления, составные типы, `package/import`, `in`, `go/defer/select`, `try/catch/finally/throw` |
| Unsafe | ключевое слово `unsafe`, **фон всего unsafe-блока**, `malloc/calloc/realloc/free/memcpy/memset/slice` (подсвечиваются только внутри `unsafe`, как требует компилятор), приведения `(*T)(p)` и `uintptr(p)` |
| Типы | встроенные, `error/Exception`, пользовательские (собираются из `type X`), std-типы (`sync.WaitGroup`, `time.Duration`), параметры дженериков `[T, U any]` с областью видимости объявления, ограничения `comparable`, `~int` |
| Функции | объявления, вызовы, методы, встроенные (`len`, `append`, `sizeof`…), std (`fmt.Println`), перегруженные операторы `func (a Money) +(b Money)`, `[]` |
| Пакеты | пути импорта, имена и псевдонимы пакетов, `package main`, члены пакетов (`time.Second`) |
| Идентификаторы | переменные, поля, объявления полей структур, метки `outer:` / `break outer` |
| Литералы | `true/false`, `nil`, объявленные `const`, целые, дробные, `0x/0b/0o` |
| Строки | `"…"`, `` `raw` ``, f-строки: текст, `{ }`, выражения внутри (подсвечены как код), спецификатор `:02d`, escape-последовательности, `{{ }}`, символы `'a'` |
| Комментарии | обычные, директивы `//gocpy:ignore:unused`, TODO/FIXME/XXX/HACK/NOTE |
| Аннотации | `@throws`, `@overload`, остальные (`@packed @align @inline @noinline @hot @cold @nogc @export @extern @target @deprecated`), интринсики `@be_to_le/@le_to_be`, неизвестные аннотации отдельным цветом |
| Операторы | арифметика, присваивание, сравнение и логика, указатели и адреса `*p &x`, проброс ошибки `?`, канал `<-`, скобки, пунктуация, недопустимые символы |
| YAML | ключи, строки, числа, булевы, комментарии, разметка (для `gocpy.yml` и `<file>.yml`) |
| Интерфейс | фон, текст, номера строк, текущая строка, выделение, курсор, парная скобка, найденное совпадение |

## Установка

1. Распакуйте `Gocpy-IDE-0.1.0-macOS.zip`.
2. Дважды кликните `install.command`. Он скопирует приложение в `/Applications`, снимет карантин Gatekeeper и добавит команду `gocpy-ide`.
   Можно и вручную: перетащите приложение в `/Applications` и выполните `xattr -dr com.apple.quarantine "/Applications/Gocpy IDE.app"`.
3. Запустите **Gocpy IDE** из Launchpad или Spotlight. Из терминала: `gocpy-ide ~/my-project`.

Для запуска программ нужен сам компилятор gocpy, а также clang и `bdw-gc`: `brew install bdw-gc`. Проверить окружение можно командой `gocpy doctor`. Если `gocpy` не лежит в PATH, укажите полный путь в настройках.

Приложение подписано только ad-hoc, без Developer ID, поэтому снимать карантин нужно один раз.

## Где хранятся данные

- настройки и цвета — `~/Library/Application Support/GocpyIDE/settings.json`;
- недавние проекты — `~/Library/Application Support/GocpyIDE/state.json`;
- профиль окна — `~/Library/Application Support/GocpyIDE/window-profile`;
- лог — `~/Library/Logs/GocpyIDE.log`.

## Безопасность

Сервер слушает только `127.0.0.1` на случайном порту. Каждый запрос, включая WebSocket, должен нести случайный токен этого запуска. Поэтому другие сайты в вашем браузере не могут обратиться к терминалу. Пути файловых операций проверяются: выйти за пределы проекта нельзя. После закрытия окна IDE завершается через 5 секунд.

## Сборка из исходников

```sh
# нужны Go 1.22+ и Node 18+ (Node — только для пересборки UI)
make run          # собрать и запустить для текущей системы
make app          # dist/Gocpy IDE.app (arm64 + amd64) + install.command
```

Скомпилированный UI лежит в `web/dist`, поэтому для `go build` Node не нужен.

```
main.go            запуск, HTTP-сервер, токен, автозавершение
app.go             API: проект, файлы, дерево, настройки, запуск, нативные диалоги
term.go            PTY-сессии (shell и run), WebSocket, события
window_darwin.go   открытие окна (Chrome/Edge/Brave --app или браузер по умолчанию)
frontend/src/
  lexer.js         лексер и семантический анализ gocpy + YAML
  categories.js    таблица подсвечиваемых элементов и цветов по умолчанию
  editor.js        CodeMirror 6: подсветка, отступы, сворачивание
  terminal.js      xterm.js ↔ PTY
  main.js          интерфейс: меню, проводник, настройки, запуск
packaging/         Info.plist, иконка, лаунчер, make-app.sh, install.command
```
